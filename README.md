# 📊 WhatsApp Chat Analyzer

A Python-based Data Science web application designed to analyze, visualize, and extract meaningful insights from WhatsApp chat exports. 

## 🚀 Features
* **Message Statistics:** Total messages, words, media shared, and links sent.
* **Timeline Analysis:** Monthly and daily timeline charts to track chatting activity patterns.
* **Activity Maps:** Most busy days of the week and busiest hours of the day.
* **Emoji Analysis:** Most frequently used emojis along with their usage statistics.
* **User Activity:** Identifies the most active users in group chats.
* **Word Cloud:** Visual representation of the most commonly used words in the chat.

## 🛠️ Tech Stack
* **Python**
* **Pandas & NumPy** (Data Manipulation & Preprocessing)
* **Streamlit** (Interactive Web App UI)
* **Matplotlib & Seaborn / Plotly** (Data Visualization)
* **Urlextract** (Link Extraction)
* **Emoji** (Emoji Processing)
